# 3D Flip for KDE Plasma

**A Windows 7 Aero Flip 3D-inspired window switcher for KDE Plasma.**

Bring back the iconic Windows 7 window-switching experience to KDE Plasma with a three-dimensional perspective layout.

## About

3D Flip is a custom KWin window switcher inspired by the legendary **Windows 7 Aero Flip 3D**.

The project aims to recreate the visual experience of navigating through open windows in a 3D space, bringing a nostalgic desktop effect to modern KDE Plasma environments.

## Features

- 3D perspective window switching.
- Real window thumbnails.
- Depth and scaling effects.
- Inspired by Windows 7 Aero Flip 3D.
- Designed for KDE Plasma and KWin.

## Requirements

- KDE Plasma 6.8.
- KWin.
